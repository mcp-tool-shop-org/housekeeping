# Repo-first rule

No coding begins until all of these are true:

1. The GitHub repository exists.
2. The local folder is a git repository.
3. `origin` points at the correct repository.
4. An initial scaffold commit is pushed and visible on GitHub.
5. Default branch is `main`.

The `lifecycle` findings enforce the parts a sweep can see: a repository with
no commits, and a default branch that is not `main`.
